## ТЕОРИЯ

### 1. Разбиване на интервал и суми на Дарбу

#### Разбиване (Partition)

**Разбиване** P на [a, b] = наредена наредица:
$$P: \quad a = x_0 < x_1 < x_2 < \cdots < x_n = b$$

**Подинтервали**: $[x_{i-1}, x_i]$, дължина $\Delta x_i = x_i - x_{i-1}$, $\sum_{i=1}^n \Delta x_i = b - a$.

**Норма на разбиване**: $\|P\| = \max_{1 \le i \le n} \Delta x_i$

---

#### Суми на Дарбу

Нека f е **ограничена** в [a, b]. За всеки подинтервал $[x_{i-1}, x_i]$:

$$M_i = \sup_{x \in [x_{i-1}, x_i]} f(x), \qquad m_i = \inf_{x \in [x_{i-1}, x_i]} f(x)$$

**Голяма сума на Дарбу** (upper sum):
$$S(f, P) = \sum_{i=1}^n M_i \Delta x_i$$

**Малка сума на Дарбу** (lower sum):
$$s(f, P) = \sum_{i=1}^n m_i \Delta x_i$$

**Очевидно**: $m_i \le M_i$ за всяко $i$, следователно $s(f, P) \le S(f, P)$.

**Геометрично**: s(f,P) = площта на вписаните правоъгълници; S(f,P) = площта на описаните.

```
    |‾‾‾|     |‾|
    |   |‾‾‾‾‾| |
____|   |     | |____
a   x1  x2   x3     b

Горните правоъгълници → S(f,P)
Долните правоъгълници → s(f,P)
```

---

### 2. Монотонност при добавяне на точки (Рафиниране)

**Твърдение**: Ако $P' \supseteq P$ (P' е рафиниране на P, т.е. добавени са нови точки), то:
$$s(f, P) \le s(f, P') \qquad \text{и} \qquad S(f, P') \le S(f, P)$$

*Малките суми не намаляват, а големите не нарастват.*

**Доказателство** (за S, случаят с s е аналогичен):

Достатъчно е да разгледаме добавянето на **една точка** x' към P в интервала $[x_{k-1}, x_k]$.

Нека $M_k = \sup_{[x_{k-1}, x_k]} f$, $M_k' = \sup_{[x_{k-1}, x']} f$, $M_k'' = \sup_{[x', x_k]} f$.

Тъй като $[x_{k-1}, x'] \subseteq [x_{k-1}, x_k]$: $M_k' \le M_k$.  
Тъй като $[x', x_k] \subseteq [x_{k-1}, x_k]$: $M_k'' \le M_k$.

Следователно:
$$M_k' (x' - x_{k-1}) + M_k'' (x_k - x') \le M_k(x' - x_{k-1}) + M_k(x_k - x') = M_k \Delta x_k$$

Всички останали членове на сумата остават непроменени. Значи $S(f, P') \le S(f, P)$. □

### 3. Дефиниция на Риманов интеграл (чрез Дарбу)

**Горен интеграл** на Дарбу:
$$\overline{\int_a^b} f(x)dx = \inf_P S(f, P)$$

**Долен интеграл** на Дарбу:
$$\underline{\int_a^b} f(x)dx = \sup_P s(f, P)$$

**Лема**: За всеки две разбивания P₁ и P₂: $s(f, P_1) \le S(f, P_2)$.  
*Доказателство*: Разгледай $P' = P_1 \cup P_2$ — рафиниране на двете; $s(f, P_1) \le s(f, P') \le S(f, P') \le S(f, P_2)$.

Следва: $\underline{\int_a^b} f \le \overline{\int_a^b} f$.

**Дефиниция (Риман/Дарбу)**: f е **интегруема по Риман** в [a, b], ако:
$$\overline{\int_a^b} f(x)dx = \underline{\int_a^b} f(x)dx$$

и общата стойност се означава с $\displaystyle\int_a^b f(x)dx$.

---

### 4. Критерий за интегруемост

**Теорема**: f е интегруема по Риман в [a, b] тогава и само тогава, когато:
$$\forall \varepsilon > 0 \; \exists \text{ разбиване } P: \; S(f, P) - s(f, P) < \varepsilon$$

**Доказателство:**

**(⟹)** Нека f е интегруема. Тогава $\overline{\int} f = \underline{\int} f = I$.

По дефиниция на инфимум: ∃P₁: $S(f,P_1) < I + \varepsilon/2$.  
По дефиниция на супремум: ∃P₂: $s(f,P_2) > I - \varepsilon/2$.

Нека $P = P_1 \cup P_2$. Тогава:
$$S(f,P) \le S(f,P_1) < I + \varepsilon/2 \qquad \text{и} \qquad s(f,P) \ge s(f,P_2) > I - \varepsilon/2$$
$$S(f,P) - s(f,P) < \varepsilon \quad \checkmark$$

**(⟸)** Нека ∀ε>0 ∃P: S(f,P)−s(f,P) < ε. Тогава:
$$0 \le \overline{\int} f - \underline{\int} f \le S(f,P) - s(f,P) < \varepsilon$$

Тъй като е вярно за произволно ε > 0: $\overline{\int} f = \underline{\int} f$. □

---

### 5. Интегруемост на непрекъснатите функции

**Теорема**: Ако f е непрекъсната в [a, b], то f е интегруема по Риман.

**Теорема на Кантор** (без доказателство): Всяка непрекъсната функция в краен затворен интервал е **равномерно непрекъсната**.

Т.е. ∀ε > 0, ∃δ > 0: |x − y| < δ ⟹ |f(x) − f(y)| < ε/(b−a).

**Доказателство на интегруемостта**:

Дадено ε > 0. По теоремата на Кантор: ∃δ > 0 такова, че за |x−y| < δ: |f(x)−f(y)| < ε/(b−a).

Вземаме разбиване P с $\|P\| < \delta$. За всяко $[x_{i-1}, x_i]$ с дължина $\Delta x_i < \delta$:
$$M_i - m_i \le \sup_{x,y \in [x_{i-1}, x_i]} |f(x) - f(y)| < \frac{\varepsilon}{b-a}$$

(защото |x−y| ≤ Δxᵢ < δ)

Следователно:
$$S(f,P) - s(f,P) = \sum_{i=1}^n (M_i - m_i)\Delta x_i < \frac{\varepsilon}{b-a} \sum_{i=1}^n \Delta x_i = \frac{\varepsilon}{b-a} \cdot (b-a) = \varepsilon$$

По критерия от т. 4: f е интегруема. □

### 6. Основни свойства на Римановия интеграл (без доказателство)

1. **Линейност**: $\int_a^b (\alpha f + \beta g)\,dx = \alpha \int_a^b f\,dx + \beta \int_a^b g\,dx$

2. **Адитивност по интервала**: $\int_a^b f\,dx = \int_a^c f\,dx + \int_c^b f\,dx$ за $c \in [a,b]$

3. **Монотонност**: Ако $f(x) \le g(x)$ в [a,b], то $\int_a^b f\,dx \le \int_a^b g\,dx$

4. **Интегриране на неравенства**: $m(b-a) \le \int_a^b f\,dx \le M(b-a)$, където $m = \min f$, $M = \max f$

5. **Абсолютна стойност**: $\left|\int_a^b f\,dx\right| \le \int_a^b |f|\,dx$

6. **Произведение**: Ако f, g са интегруеми, то fg е интегруема

---

### 7. Теорема за средната стойност на интеграла

**Теорема**: Ако f е непрекъсната в [a, b], то ∃ c ∈ [a, b] такова, че:
$$\int_a^b f(x)\,dx = f(c)(b - a)$$

**Доказателство**:

Нека $m = \min_{[a,b]} f$ и $M = \max_{[a,b]} f$ (съществуват по Вайерщрас, тъй като f е непрекъсната).

По свойство 4: $m(b-a) \le \int_a^b f\,dx \le M(b-a)$

Делим на (b−a) > 0:
$$m \le \frac{1}{b-a}\int_a^b f\,dx \le M$$

Нека $\mu = \dfrac{1}{b-a}\int_a^b f\,dx$. Тогава $m \le \mu \le M$.

По **теоремата за средните стойности** (Болцано-Вайерщрас / теорема за промеждутъчните стойности): тъй като f е непрекъсната и приема стойностите m и M, тя приема и всяка стойност между тях. Значи ∃ c ∈ [a, b]: $f(c) = \mu$.

Следователно:
$$f(c) = \frac{1}{b-a}\int_a^b f(x)\,dx \implies \int_a^b f(x)\,dx = f(c)(b-a) \quad □$$

### 8. Теорема на Нютон-Лайбниц

#### Функция на горната граница

Нека f е непрекъсната в [a, b]. Дефинираме:
$$F(x) = \int_a^x f(t)\,dt, \qquad x \in [a, b]$$

**Теорема (Нютон-Лайбниц, I часть)**: F е диференцируема в [a, b] и:
$$F'(x) = \frac{d}{dx}\int_a^x f(t)\,dt = f(x)$$

**Доказателство**:

Разглеждаме разностното частно:
$$\frac{F(x+h) - F(x)}{h} = \frac{1}{h}\left[\int_a^{x+h} f(t)\,dt - \int_a^x f(t)\,dt\right] = \frac{1}{h}\int_x^{x+h} f(t)\,dt$$

По **Теоремата за средната стойност на интеграла** (т. 7):
$$\frac{1}{h}\int_x^{x+h} f(t)\,dt = f(c_h)$$

за някое $c_h$ между x и x+h.

При $h \to 0$: $c_h \to x$. Тъй като f е **непрекъсната**: $f(c_h) \to f(x)$.

Следователно:
$$F'(x) = \lim_{h \to 0} \frac{F(x+h) - F(x)}{h} = \lim_{h \to 0} f(c_h) = f(x) \quad □$$

---

#### Нютон-Лайбниц за изчисляване (Барова формула)

**Следствие**: Ако Φ е произволна **примитивна функция** на f (т.е. Φ'(x) = f(x)), то:
$$\int_a^b f(x)\,dx = \Phi(b) - \Phi(a) = \Big[\Phi(x)\Big]_a^b$$

**Доказателство**: F(x) = ∫_a^x f(t)dt е примитивна (F'=f). Φ е и друга примитивна → Φ(x) = F(x) + C.

$$\Phi(b) - \Phi(a) = [F(b) + C] - [F(a) + C] = F(b) - F(a) = \int_a^b f(t)\,dt \quad □$$

### 9. Приложение — изчисляване на определени интеграли

#### Стъпка по стъпка:

1. Намери примитивна Φ(x) (неопределен интеграл)
2. Приложи барова формула: $\int_a^b f = \Phi(b) - \Phi(a)$

**Пример 1**:
$$\int_0^1 x^2\,dx = \left[\frac{x^3}{3}\right]_0^1 = \frac{1}{3} - 0 = \frac{1}{3}$$

**Пример 2**:
$$\int_0^{\pi} \sin x\,dx = \Big[-\cos x\Big]_0^{\pi} = (-\cos\pi) - (-\cos 0) = 1 + 1 = 2$$

**Пример 3**:
$$\int_1^e \frac{1}{x}\,dx = \Big[\ln x\Big]_1^e = \ln e - \ln 1 = 1 - 0 = 1$$
