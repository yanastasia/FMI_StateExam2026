# Тема 29: Уравнения на права в равнината.

---

## ТЕОРИЯ

### 1. Векторно-параметрично уравнение на права

Нека M₀(x₀, y₀) е точка на правата и **v** = (a, b) ≠ **0** е **направляващ вектор** (паралелен на правата).

**Точка M(x, y) лежи на правата ⟺ $\overrightarrow{M_0M} \parallel \vec{v}$**, т.е.:

$$\vec{r}(t) = \vec{r}_0 + t\vec{v}, \qquad t \in \mathbb{R}$$

или:
$$\overrightarrow{OM}(t) = \overrightarrow{OM_0} + t\vec{v} = (x_0 + ta,\; y_0 + tb)$$

**Геометрично**: При t = 0 → M₀; t > 0 → в посока **v**; t < 0 → в обратна посока.

---

### 2. Координатни (скаларни) параметрични уравнения

Разписваме векторното уравнение координатно:

$$\boxed{\begin{cases} x = x_0 + at \\ y = y_0 + bt \end{cases}} \qquad t \in \mathbb{R}$$

**При b ≠ 0 и a ≠ 0** можем да елиминираме t:
$$\frac{x - x_0}{a} = \frac{y - y_0}{b} \quad \text{(симетрично уравнение)}$$

---

### 3. Теорема за общото уравнение на права (Декартово)

**Теорема**: Всяка права в равнината (в афинна координатна система) може да се опише с уравнение:
$$Ax + By + C = 0, \qquad (A, B) \neq (0, 0)$$

Обратно: всяко такова уравнение задава права.

**Доказателство (скица)**:

*Права → уравнение*: Нека правата минава през M₀(x₀, y₀) с направляващ вектор **v** = (a, b). Нормален вектор е **n** = (b, −a) (перпендикулярен на **v**). Точка M(x, y) е на правата ⟺ $\overrightarrow{M_0M} \perp \vec{n}$... изчакай — в афинна система нямаме скаларно произведение. Вместо това:

Условието $\overrightarrow{M_0M} \parallel \vec{v}$ означава: $(x-x_0, y-y_0) = t(a,b)$, т.е.:
$$b(x - x_0) - a(y - y_0) = 0 \implies bx - ay + (-bx_0 + ay_0) = 0$$
Това е от вида Ax + By + C = 0 с A = b, B = −a, C = ay₀ − bx₀. ✓

*Уравнение → права*: Ако B ≠ 0, при x = 0 → y = −C/B; при x = 1 → y = (−A−C)/B. Двете точки определят права. Ако B = 0 → A ≠ 0 → x = −C/A (вертикална права). ✓ □

**Еквивалентност**: $A_1x + B_1y + C_1 = 0$ и $A_2x + B_2y + C_2 = 0$ задават **едно и също** ⟺ ∃λ ≠ 0: $A_1 = \lambda A_2$, $B_1 = \lambda B_2$, $C_1 = \lambda C_2$.

**Вектор n = (A, B) е нормален** (перпендикулярен) на правата (в ортонормирана система).  
**Вектор v = (−B, A) (или (B, −A)) е направляващ** на правата.

---

### 4. Взаимно положение между две прави в равнината

Дадени: $g_1: A_1x + B_1y + C_1 = 0$ и $g_2: A_2x + B_2y + C_2 = 0$.

| Взаимно положение | Условие |
|------------------|---------|
| **Съвпадащи** | $\dfrac{A_1}{A_2} = \dfrac{B_1}{B_2} = \dfrac{C_1}{C_2}$ (пропорционални коефициенти) |
| **Успоредни** (без съвпадане) | $\dfrac{A_1}{A_2} = \dfrac{B_1}{B_2} \neq \dfrac{C_1}{C_2}$ |
| **Пресичащи се** | $\dfrac{A_1}{A_2} \neq \dfrac{B_1}{B_2}$ (системата има единствено решение) |
| **Перпендикулярни** | $A_1A_2 + B_1B_2 = 0$ (нормалите са перпендикулярни) |
| **Успоредни / съвпадащи** | $A_1B_2 = A_2B_1$ (det = 0) |

**Ъгъл между прави** (в ортонормирана система):
$$\cos\theta = \frac{|A_1A_2 + B_1B_2|}{\sqrt{A_1^2+B_1^2}\sqrt{A_2^2+B_2^2}}$$

---

### 5. Декартово уравнение — специални форми

#### Уравнение с ъглов коефициент
$$y = kx + n$$
- k = −A/B (ъглов коефициент / наклон)
- n = −C/B (отсечка от оста Oy)

**Паралелни** прави: еднакъв k  
**Перпендикулярни** прави: $k_1 \cdot k_2 = -1$

#### Уравнение в отсечки
$$\frac{x}{a} + \frac{y}{b} = 1$$
(права, пресичаща Ox в a и Oy в b; a ≠ 0, b ≠ 0)

#### Права през две точки M₁(x₁,y₁) и M₂(x₂,y₂):
$$\frac{x - x_1}{x_2 - x_1} = \frac{y - y_1}{y_2 - y_1}$$

или: $(y_2-y_1)(x-x_1) - (x_2-x_1)(y-y_1) = 0$

---

### 6. Нормално уравнение на права (в ортонормирана система)

**Нормален вектор**: **n** = (A, B). **Единичен нормален вектор**: **n₀** = (A, B)/√(A²+B²).

**Нормиране**: Делим уравнението Ax + By + C = 0 на ±√(A²+B²):

$$\boxed{x\cos\alpha + y\sin\alpha - p = 0}$$

където:
- $\cos\alpha = \pm A/\sqrt{A^2+B^2}$, $\sin\alpha = \pm B/\sqrt{A^2+B^2}$ (единичен нормален)
- $p = \mp C/\sqrt{A^2+B^2} \ge 0$ (разстояние от O до правата)

Знакът се избира така, че p ≥ 0.

---

### 7. Разстояние от точка до права

**Формула**: Разстоянието от M₁(x₁, y₁) до правата Ax + By + C = 0:

$$\boxed{d(M_1, g) = \frac{|Ax_1 + By_1 + C|}{\sqrt{A^2 + B^2}}}$$

**Геометрично**: Числото $Ax_1 + By_1 + C$ (без модул) е знаковото разстояние — положително ако M₁ е от страната на **n**, отрицателно в обратния случай.

**Извеждане**: В нормалното уравнение, за точка M₁ стойността $x_1\cos\alpha + y_1\sin\alpha - p$ е проекцията на $\overrightarrow{OM_1}$ върху **n₀** минус p = алгебричното разстояние. □

---

### 8. Полуравнини

Правата $Ax + By + C = 0$ разделя равнината на две **полуравнини**:
$$H^+ = \{(x,y) \mid Ax + By + C > 0\}$$
$$H^- = \{(x,y) \mid Ax + By + C < 0\}$$

**Свойство**: Точките M₁, M₂ са в **различни** полуравнини ⟺:
$$(Ax_1 + By_1 + C)(Ax_2 + By_2 + C) < 0$$

Точките M₁, M₂ са в **едно** полуравнина ⟺ произведението > 0.

## КАК СЕ РЕШАВАТ ЗАДАЧИ

### Тип 1: Намери уравнение на права

**Дадена точка и направляващ вектор**: $M_0(x_0, y_0)$, **v** = (a, b):
- Параметрично: $x = x_0 + at$, $y = y_0 + bt$
- Декартово: $b(x - x_0) - a(y - y_0) = 0$

**Дадена точка и нормален вектор**: $M_0(x_0, y_0)$, **n** = (A, B):
$$A(x - x_0) + B(y - y_0) = 0$$

**Дадени две точки** $M_1(x_1,y_1)$ и $M_2(x_2,y_2)$:
$$\frac{x - x_1}{x_2 - x_1} = \frac{y - y_1}{y_2 - y_1} \quad \text{или} \quad \det\begin{pmatrix}x-x_1 & x_2-x_1 \\ y-y_1 & y_2-y_1\end{pmatrix} = 0$$

---

### Тип 2: Намери разстояние от точка до права

**Пример**: d от M₁(1, 2) до 3x − 4y + 5 = 0:
$$d = \frac{|3\cdot1 - 4\cdot2 + 5|}{\sqrt{9+16}} = \frac{|3 - 8 + 5|}{\sqrt{25}} = \frac{|0|}{5} = 0$$
→ Точката лежи на правата!

**Пример**: d от M₁(3, 1) до 3x − 4y + 5 = 0:
$$d = \frac{|9 - 4 + 5|}{5} = \frac{10}{5} = 2$$

---

### Тип 3: Намери сечна точка на две прави

Реши системата $\begin{cases}A_1x + B_1y + C_1 = 0 \\ A_2x + B_2y + C_2 = 0\end{cases}$ с Cramer или Gauss.

---

### Тип 4: В коя полуравнина се намира точка?

Пресметни $F(x_0, y_0) = Ax_0 + By_0 + C$:
- F > 0 → H⁺
- F < 0 → H⁻
- F = 0 → точката лежи на правата

---

### Тип 5: Права паралелна / перпендикулярна

**Успоредна** на Ax + By + C₁ = 0, минаваща през M₀(x₀, y₀):
$$Ax + By + (-Ax_0 - By_0) = 0 \quad \text{(сам. коеф. A, B)}$$

**Перпендикулярна** на Ax + By + C = 0, минаваща през M₀(x₀, y₀):
$$Bx - Ay + (-Bx_0 + Ay_0) = 0 \quad \text{(нормалата → направляща)}$$
