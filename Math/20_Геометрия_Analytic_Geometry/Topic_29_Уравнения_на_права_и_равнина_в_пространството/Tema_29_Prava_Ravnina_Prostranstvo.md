# Тема 30: Уравнения на права и равнина в пространството.

---

## ТЕОРИЯ

### 1. Векторно-параметрично уравнение на равнина

Нека α е равнина, определена от:
- Точка M₀(x₀, y₀, z₀) ∈ α
- Два **неколинеарни** (лин. независими) вектора **u** = (a₁,a₂,a₃) и **v** = (b₁,b₂,b₃), лежащи в α

**Точка M ∈ α ⟺ $\overrightarrow{M_0M}$ е линейна комбинация на u и v:**

$$\vec{r}(s,t) = \vec{r}_0 + s\vec{u} + t\vec{v}, \qquad s, t \in \mathbb{R}$$

---

### 2. Скаларни параметрични уравнения на равнина

$$\begin{cases}
x = x_0 + a_1 s + b_1 t \\
y = y_0 + a_2 s + b_2 t \\
z = z_0 + a_3 s + b_3 t
\end{cases} \qquad s, t \in \mathbb{R}$$

---

### 3. Теорема за общото уравнение на равнина

**Теорема**: Всяка равнина в пространството се задава с уравнение:
$$Ax + By + Cz + D = 0, \qquad (A,B,C) \neq (0,0,0)$$

Обратно: всяко такова уравнение задава равнина.

**Нормален вектор**: **n** = (A, B, C) ⊥ равнината.

**Доказателство (скица)**:

*Равнина → уравнение*: Нека M₀(x₀,y₀,z₀) ∈ α с два насочващи **u**, **v**. Нормалният вектор:
$$\vec{n} = \vec{u} \times \vec{v} = (A, B, C) \neq \vec{0}$$

M(x,y,z) ∈ α ⟺ $\overrightarrow{M_0M} \perp \vec{n}$ ⟺ $\vec{n} \cdot \overrightarrow{M_0M} = 0$:
$$A(x-x_0) + B(y-y_0) + C(z-z_0) = 0 \implies Ax + By + Cz + D = 0$$
с D = −Ax₀ − By₀ − Cz₀. ✓

*Уравнение → равнина*: Ако A ≠ 0: три точки (−D/A, 0, 0), (0, −D/B, 0), (0, 0, −D/C) са неколинеарни и определят равнина с даденото уравнение. ✓ □

**Еквивалентност**: $A_1x+B_1y+C_1z+D_1=0$ и $A_2x+B_2y+C_2z+D_2=0$ задават **една и съща** равнина ⟺ ∃λ≠0: $A_1=λA_2$, $B_1=λB_2$, $C_1=λC_2$, $D_1=λD_2$.

**Специални случаи**:
- D = 0: равнината минава през началото O
- A = 0: равнината е паралелна на оста Ox
- A = B = 0: равнина, паралелна на xOy (от вид z = k)

---

### 4. Взаимно положение между две равнини

Дадени: α₁: A₁x+B₁y+C₁z+D₁=0 и α₂: A₂x+B₂y+C₂z+D₂=0 с нормали **n₁** = (A₁,B₁,C₁) и **n₂** = (A₂,B₂,C₂).

| Положение | Условие |
|-----------|---------|
| **Съвпадащи** | (A₁,B₁,C₁,D₁) = λ(A₂,B₂,C₂,D₂), λ≠0 |
| **Успоредни** (без съвпадане) | **n₁** ∥ **n₂**, т.е. (A₁,B₁,C₁) = λ(A₂,B₂,C₂), но D₁ ≠ λD₂ |
| **Пресичащи се** (по права) | **n₁** и **n₂** са неколинеарни: $\frac{A_1}{A_2} \neq \frac{B_1}{B_2}$ или др. |
| **Перпендикулярни** | **n₁** · **n₂** = 0: A₁A₂+B₁B₂+C₁C₂ = 0 |

**Ъгъл между равнини** = ъгъл между нормалите:
$$\cos\theta = \frac{|A_1A_2 + B_1B_2 + C_1C_2|}{\sqrt{A_1^2+B_1^2+C_1^2}\sqrt{A_2^2+B_2^2+C_2^2}}$$

---

### 5. Нормално уравнение на равнина

В ортонормирана система: **n₀** = (cosα, cosβ, cosγ) е **единичен нормален** вектор (направляващи косинуси).

**Нормиране** на Ax + By + Cz + D = 0: делим на ±√(A²+B²+C²):

$$\boxed{x\cos\alpha + y\cos\beta + z\cos\gamma - p = 0}$$

- $\cos\alpha = \pm A/\sqrt{A^2+B^2+C^2}$, аналогично cosβ, cosγ
- $p = \mp D/\sqrt{A^2+B^2+C^2} \ge 0$ — разстояние от O до равнината
- Знакът се избира така, че p ≥ 0

---

### 6. Разстояние от точка до равнина

**Формула**: Разстояние от M₁(x₁,y₁,z₁) до равнината Ax+By+Cz+D=0:

$$\boxed{d(M_1, \alpha) = \frac{|Ax_1 + By_1 + Cz_1 + D|}{\sqrt{A^2 + B^2 + C^2}}}$$

**Знаково разстояние**: $\delta = \dfrac{Ax_1+By_1+Cz_1+D}{\sqrt{A^2+B^2+C^2}}$ (с знак показва от коя страна на равнината е M₁).

---

### 7. Полупространства

Равнината Ax+By+Cz+D=0 разделя пространството на:
$$H^+ = \{(x,y,z) \mid Ax+By+Cz+D > 0\}$$
$$H^- = \{(x,y,z) \mid Ax+By+Cz+D < 0\}$$

**Критерий**: P, Q са в **различни** полупространства ⟺ f(P)·f(Q) < 0, където f = Ax+By+Cz+D.

---

### 8. Уравнения на права в пространството

#### 8.1. Векторно-параметрично

Дадена точка M₀(x₀,y₀,z₀) и направляващ вектор **v** = (a,b,c) ≠ **0**:

$$\vec{r}(t) = \vec{r}_0 + t\vec{v}, \qquad t \in \mathbb{R}$$

#### 8.2. Скаларни параметрични уравнения

$$\begin{cases}
x = x_0 + at \\
y = y_0 + bt \\
z = z_0 + ct
\end{cases} \qquad t \in \mathbb{R}$$

#### 8.3. Канонично (симетрично) уравнение

При a, b, c ≠ 0:
$$\frac{x - x_0}{a} = \frac{y - y_0}{b} = \frac{z - z_0}{c}$$

При c = 0 (права, паралелна на xOy):
$$\frac{x - x_0}{a} = \frac{y - y_0}{b}, \qquad z = z_0$$

#### 8.4. Права като пресечница на две равнини

$$l = \alpha_1 \cap \alpha_2: \begin{cases}
A_1x + B_1y + C_1z + D_1 = 0 \\
A_2x + B_2y + C_2z + D_2 = 0
\end{cases}$$

(нормалите **n₁**, **n₂** са неколинеарни; **v** = **n₁** × **n₂** — направляващ вектор на правата)

---

### 9. Взаимно положение на права и равнина

Нека l: $\vec{r} = \vec{r}_0 + t\vec{v}$ и α: Ax+By+Cz+D=0 с нормала **n** = (A,B,C).

| Положение | Условие |
|-----------|---------|
| **Права ∥ равнина** | **v** ⊥ **n**: Aa+Bb+Cc = 0 и M₀ ∉ α |
| **Права ⊂ равнина** | Aa+Bb+Cc = 0 и Ax₀+By₀+Cz₀+D = 0 |
| **Пресичат се** | Aa+Bb+Cc ≠ 0 |

**Ъгъл права–равнина** (допълнение до ъгъла права–нормала):
$$\sin\varphi = \frac{|Aa+Bb+Cc|}{\sqrt{A^2+B^2+C^2}\sqrt{a^2+b^2+c^2}}$$

---

### 10. Взаимно положение на две прави в пространството

Нека l₁: M₁ + t**v₁** и l₂: M₂ + t**v₂**.

| Положение | Условие |
|-----------|---------|
| **Успоредни** | **v₁** ∥ **v₂** и M₁ ∉ l₂ |
| **Съвпадащи** | **v₁** ∥ **v₂** и M₁ ∈ l₂ |
| **Пресичащи се** | **v₁** и **v₂** неколинеарни + $\overrightarrow{M_1M_2}$, **v₁**, **v₂** компланарни (смесено произв.=0) |
| **Кръстосани (скрещиващи се)** | **v₁** и **v₂** неколинеарни + смесеното произведение ≠ 0 |

**Разстояние между кръстосани прави**:
$$d = \frac{|(\overrightarrow{M_1M_2}, \vec{v}_1, \vec{v}_2)|}{|\vec{v}_1 \times \vec{v}_2|}$$

---

## КАК СЕ РЕШАВАТ ЗАДАЧИ

### Тип 1: Намери уравнение на равнина

**По точка и нормален вектор** M₀(x₀,y₀,z₀), **n** = (A,B,C):
$$A(x-x_0) + B(y-y_0) + C(z-z_0) = 0$$

**По три точки** A, B, C:
1. **u** = B − A, **v** = C − A
2. **n** = **u** × **v** = (A, B, C) (векторно произведение)
3. Уравнение: A(x−x_A) + B(y−y_A) + C(z−z_A) = 0

**По точка и две лежащи прави** (направляващи вектори **u**, **v**): n = u × v.

---

### Тип 2: Разстояние от точка до равнина

**Пример**: d от M₁(1, 2, 3) до 2x − y + 2z − 6 = 0:
$$d = \frac{|2\cdot1 - 1\cdot2 + 2\cdot3 - 6|}{\sqrt{4+1+4}} = \frac{|2-2+6-6|}{3} = \frac{0}{3} = 0$$
→ Точката лежи на равнината!

**Пример**: d от M₁(3, 0, 0) до 2x − y + 2z − 6 = 0:
$$d = \frac{|6-0+0-6|}{3} = \frac{0}{3} = 0 \quad \text{(и тази точка е на равнината)}$$

---

### Тип 3: Пресечна точка на права и равнина

Заместваме параметричните уравнения на правата в уравнението на равнината:
$$A(x_0+at) + B(y_0+bt) + C(z_0+ct) + D = 0$$
$$t = -\frac{Ax_0+By_0+Cz_0+D}{Aa+Bb+Cc}$$
→ Заместваме t назад в уравненията на правата.

---

### Тип 4: Намери уравнение на правата — пресечница на две равнини

Системата от двете уравнения директно задава правата.  
За направляващ вектор: **v** = **n₁** × **n₂**.  
За точка: реши системата с подходящо фиксирана координата (напр. z = 0).

---
