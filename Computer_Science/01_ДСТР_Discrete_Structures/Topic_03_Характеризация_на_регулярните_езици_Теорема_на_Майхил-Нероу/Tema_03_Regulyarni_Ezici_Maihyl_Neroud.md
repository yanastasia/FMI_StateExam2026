# Тема 3: Характеризация на регулярните езици. Теорема на Майхил-Нероуд.

---

## ТЕОРИЯ

### 1. Основни дефиниции

**Азбука** Σ — крайно непразно множество от символи. **Дума** — крайна редица от символи. **Σ\*** — всички крайни думи над Σ, включително празната дума ε. **Език** — L ⊆ Σ\*.

**Регулярен език** — език, зададен чрез регулярен израз (краен брой операции обединение ∪, конкатенация ·, итерация на Клини \* върху ∅, {ε}, {a}).

**Детерминиран краен автомат (ДКА)** — петорка:
$$A = (Q, \Sigma, \delta, q_0, F)$$
- Q — крайно множество от **състояния**
- Σ — входна азбука
- δ : Q × Σ → Q — **функция на преходите**
- q₀ ∈ Q — **начално** състояние
- F ⊆ Q — **финални** (приемащи) състояния

**Тотален** ДКА — δ е дефинирана за всяка двойка (q, a).

**Разширена функция на преходите** δ\* : Q × Σ\* → Q:
- δ\*(q, ε) = q
- δ\*(q, wa) = δ(δ\*(q, w), a)

**Автоматен език**: L(A) = { w ∈ Σ\* | δ\*(q₀, w) ∈ F }

**Теорема на Клини**: Език L е регулярен ⟺ L се разпознава от краен автомат.

---

### 2. Релация на Майхил-Нероуд ≡_L

За език L ⊆ Σ\* и думи u, v ∈ Σ\*:
$$u \equiv_L v \iff \forall x \in \Sigma^*: ux \in L \Leftrightarrow vx \in L$$

> u и v са **неразличими** от L чрез каквото и да е продължение x.

**Интуиция**: u ≡_L v означава, че от гледна точка на „какво предстои", u и v са идентични — за разпознаването на L няма значение кое от двете е прочетено.

---

### 3. ≡_L е релация на еквивалентност

**Рефлексивност**: u ≡_L u — ux ∈ L ⟺ ux ∈ L (тривиално). ✓

**Симетричност**: Ако u ≡_L v → (ux ∈ L ⟺ vx ∈ L) → (vx ∈ L ⟺ ux ∈ L) → v ≡_L u. ✓

**Транзитивност**: Нека u ≡_L v и v ≡_L z. Тогава за всяко x:
ux ∈ L ⟺ vx ∈ L ⟺ zx ∈ L, следователно u ≡_L z. ✓

---

### 4. ≡_L е дясно инвариантна

**Дясна инвариантност**: u ≡_L v ⟹ ∀y ∈ Σ\*: uy ≡_L vy

**Доказателство**: Нека u ≡_L v и y е произволна дума. За да докажем uy ≡_L vy, трябва за всяко x:
$$(uy)x \in L \Leftrightarrow (vy)x \in L$$
Но z = yx е продължение. Понеже u ≡_L v → uz ∈ L ⟺ vz ∈ L → u(yx) ∈ L ⟺ v(yx) ∈ L. ✓

---

### 5. Индекс на ≡_L → тотален ДКА с n състояния

**Индекс** на ≡_L = броят на класовете на еквивалентност.

**Теорема**: Ако ≡_L има краен индекс n, тогава L се разпознава от тотален ДКА с точно n състояния.

**Конструкция** (автоматът на Майхил-Нероуд):

Нека класовете на ≡_L са [w₁], [w₂], …, [wₙ].

- **Състояния** Q = { [w] | w ∈ Σ\* } (класовете на ≡_L)
- **Начално** состояние: [ε]
- **Преходи**: δ([w], a) = [wa]
- **Финални** состояния: F = { [w] | w ∈ L }

**Коректност на конструкцията**:
- δ е добре дефинирана: ако w ≡_L w', то wa ≡_L w'a (дясна инвариантност) → [wa] = [w'a]. ✓
- F е добре дефинирано: ако w ≡_L w', вземаме x = ε → (w ∈ L ⟺ w' ∈ L). ✓
- **Твърдение**: δ\*([ε], w) = [w] (по индукция по |w|).
  - База: δ\*([ε], ε) = [ε]. ✓
  - Стъпка: δ\*([ε], wa) = δ(δ\*([ε], w), a) = δ([w], a) = [wa]. ✓
- Думата w се приема ⟺ [w] ∈ F ⟺ w ∈ L. ✓ □

---

### 6. Тотален ДКА с n ≤ n → индекс на ≡_L е ≤ n

**Теорема**: Ако L се разпознава от тотален ДКА с n състояния, то индексът на ≡_L е ≤ n.

**Доказателство**: Нека A = (Q, Σ, δ, q₀, F) с |Q| = n. Дефинираме:
$$u \sim_A v \iff \delta^*(q_0, u) = \delta^*(q_0, v)$$

Ако u ∼_A v, то за всяко x: δ\*(q₀, ux) = δ\*(δ\*(q₀,u), x) = δ\*(δ\*(q₀,v), x) = δ\*(q₀, vx). Следователно ux ∈ L ⟺ vx ∈ L → u ≡_L v.

Значи **∼_A рафинира ≡_L**: всеки клас на ≡_L съдържа цели класове на ∼_A. Броят на класовете на ∼_A ≤ |Q| = n → броят на класовете на ≡_L ≤ n. □

---

### 7. Теорема на Майхил-Нероуд

**Теорема**: Език L ⊆ Σ\* е регулярен ⟺ релацията ≡_L има **краен индекс**.

**Доказателство**:

**(⟸)** Ако ≡_L има краен индекс → (от т. 5) → L се разпознава от тотален ДКА → L е автоматен → по Клини: L е регулярен. ✓

**(⟹)** Ако L е регулярен → по Клини L се разпознава от краен ДКА с n състояния → (от т. 6) → индексът на ≡_L ≤ n < ∞. ✓ □

**Следствие**: Броят на състоянията на **минималния** тотален ДКА за L = индексът на ≡_L.

---

### 8. Доказване на нерегулярност

За да докажем, че L **не е регулярен** чрез Майхил-Нероуд:

Намираме безкрайно множество от думи { w₁, w₂, w₃, … }, такова че за всеки i ≠ j: wᵢ и wⱼ са **различими** — съществува x, за което точно едно от wᵢx, wⱼx е в L.

Тогава ≡_L има безкраен индекс → L не е регулярен. □

**Пример**: L = { aⁿbⁿ | n ≥ 0 }. Думите aⁱ и aʲ (i ≠ j) са различими: вземаме x = bⁱ → aⁱbⁱ ∈ L, но aʲbⁱ ∉ L. Безкрайно много класове → L не е регулярен.

### Тип 1: Построяване на минимален тотален ДКА по Майхил-Нероуд

*Появява се в: 2022 Jun, 2021 Jun, 2019 Jun, 2017 Sep, 2016 Jun (и др.)*

**Алгоритъм: Намери класовете на ≡_L**

**Стъпка 1**: Определи „остатъчните езици" (right quotients). Два префикса u и v са в един клас ⟺ { x | ux ∈ L } = { x | vx ∈ L }.

**Стъпка 2**: Изброй всички различни остатъчни езици — всеки е отделен клас (= отделно състояние).

**Стъпка 3**: Построй таблицата на преходите: δ([u], a) = [ua].

**Стъпка 4**: Маркирай финалните класове: [u] ∈ F ⟺ u ∈ L (т.е. ε ∈ остатъчния език на u).

**Шаблон за обосновка:**

> „Класовете на ≡_L са [w₁], …, [wₖ], защото остатъчните езици L/wᵢ = { … } са по двойки различни, и всяка дума над Σ попада в точно един от тях (защото …). Следователно минималният ДКА има k състояния."

**Пример**: L = { w ∈ {a,b}\* | w завършва на ab }

Остатъчни езици:
- [ε] = [b] : нужно е продължение от вида ab…  → L/ε = L/b = { xab… | … }
- Практически намираме: класове = { q_∅, q_a, q_ab } → 3 стояния

По-систематично — следвай пример от таблицата:

| Клас | Представител | Финален? | δ(·, a) | δ(·, b) |
|------|-------------|----------|---------|---------|
| q₀ | ε | не | q_a | q₀ |
| q_a | a | не | q_a | q_ab |
| q_ab | ab | **да** | q_a | q₀ |

### Тип 2: Доказване на нерегулярност чрез Майхил-Нероуд

*Появява се в: 2022 Sep, 2021 Sep, 2020 Jun, 2018 Jun (и др.)*

**Алгоритъм:**

1. Предположи, че L не е регулярен.
2. Намери безкрайна редица w₁, w₂, … такава, че за i ≠ j → wᵢ ≢_L wⱼ.
3. За всяка двойка i ≠ j: посочи конкретно x = xᵢⱼ такова, че wᵢx ∈ L и wⱼx ∉ L (или обратното).
4. Заключи: ≡_L има безкраен индекс → L не е регулярен.

**Шаблон за обосновка:**

> „Разглеждаме думите wₙ = … (n = 0, 1, 2, …). Твърдим, че те са по двойки ≡_L-неразличими. За i ≠ j вземаме x = …: wᵢx = … ∈ L, защото …, но wⱼx = … ∉ L, защото … Следователно ≡_L има безкрайно много класове → L не е регулярен по теоремата на Майхил-Нероуд."

**Чести примери:**
| Език | Думи за разграничаване | Разграничаващ суфикс |
|------|----------------------|----------------------|
| { aⁿbⁿ } | wₙ = aⁿ | x = bⁿ |
| { ww \| w ∈ {a,b}\* } | wₙ = aⁿb | x = aⁿ |
| { aⁿ² } | wₙ = aⁿ² | различен брой a след тях |
| { aᵖ \| p просто } | wₙ = aⁿ! | x = aⁿ!·(k-1) за подходящо k |

---

### Тип 3: Проверка дали два ДКА разпознават един и същ език (еквивалентност)

*Появява се по-рядко, но свързано — чрез минимизация на автомата*

**Метод**: Минимизирай и двата автомата (намери ≡_L класовете), сравни. Ако минималните ДКА са изоморфни → езиците съвпадат.
