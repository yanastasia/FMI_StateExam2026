# Тема 4: Лема за разрастването за контекстносвободни езици. Незатвореност относно сечение и допълнение.

---

## ТЕОРИЯ

### 1. Основни дефиниции

**Контекстносвободна граматика (КСГ)** — четворка G = (V, Σ, R, S), където:
- V — крайно множество от **нетерминали** (променливи)
- Σ — крайно множество от **терминали** (V ∩ Σ = ∅)
- R — крайно множество от **правила** от вид A → α, (A ∈ V, α ∈ (V ∪ Σ)\*)
- S ∈ V — **начален символ**

„Контекстносвободна" — A може да се замества с α независимо от символите около него.

**Извод**: Ако βAγ е дума и A → α е правило, тогава: βAγ ⟹ βαγ

**Транзитивно затваряне**: ω₁ ⟹\* ω₂ (извеждане за краен брой стъпки)

**Език на граматиката**: L(G) = { w ∈ Σ\* | S ⟹\* w }

**Контекстносвободен език (КСЕ)** — език L, за който ∃ КСГ G : L(G) = L.

---

### 2. Дърво на извод

**Дърво на извод** за дума w в граматика G:
- **Корен** — начален символ S
- **Вътрешни върхове** — нетерминали
- **Деца на A** — X₁, X₂, …, Xₖ ако е приложено правило A → X₁X₂…Xₖ
- **Листа** (ляво→дясно) — образуват думата w

> Дървото показва не само че w ∈ L(G), но и нейната **синтактична структура** (може да е неединствено — амбигуитет).

---

### 3. Затвореност относно регулярни операции (без доказателство)

Нека L₁, L₂ са КСЕ с граматики с начални символи S₁, S₂. Добавяме нов S и:

| Операция | Ново правило |
|----------|-------------|
| L₁ ∪ L₂ | S → S₁ \| S₂ |
| L₁ · L₂ | S → S₁S₂ |
| L₁\* | S → S₁S \| ε |

> КСЕ са **затворени** относно ∪, ·, \*. **НЕ са затворени** относно ∩ и ¬ (виж т. 6–7).

---

### 4. Лема за разрастването за КСЕ (Pumping Lemma)

**Лема**: Ако L е КСЕ, то ∃ p ∈ ℕ (константа на разрастване), такова че:

∀ z ∈ L с |z| ≥ p, ∃ разбиване z = uvwxy, при което:
1. **|vwx| ≤ p**
2. **|vx| > 0** (v и x не са едновременно ε)
3. **∀ i ≥ 0: uvⁱwxⁱy ∈ L**

---

### 5. Доказателство на лемата

Нека G = (V, Σ, R, S) е в **нормална форма на Чомски (НФЧ)**: правила A → BC или A → a, плюс евентуално S → ε.

Нека |V| = m. Избираме **p = 2ᵐ**.

**Ключово наблюдение**: Двоично дърво с височина ≤ m има ≤ 2ᵐ листа. Ако |z| ≥ 2ᵐ = p, то дървото на извод за z има път от корена до листо с > m вътрешни (нетерминални) върха.

**По принципа на Дирихле**: По пътя има > m нетерминала, но различните нетерминали са само m → поне един нетерминал **A се повтаря** по пътя.

Избираме **двете най-долни появи** на A (в долните m+1 върха на пътя):
- По-горна поява на A ⟹\* **vwx** (включва по-долното поддърво)
- По-долна поява на A ⟹\* **w**

Следователно имаме:
$$A \Rightarrow^* vAx \quad \text{и} \quad A \Rightarrow^* w$$

Разрастваме произволно: S ⟹\* u**A**y ⟹\* u·vⁱ**A**xⁱ·y ⟹\* u·vⁱ·w·xⁱ·y ∈ L.

**Защо ограниченията:**
- **|vx| > 0**: Избираме появите в низходящ ред → v, x не са ε (иначе нямаше смяна).
- **|vwx| ≤ p**: Избираме двете появи в **долните m+1 върха** → поддървото на по-горната A има височина ≤ m → поражда дума с дължина ≤ 2ᵐ = p. □

---

### 6. Пример: { aⁿbⁿcⁿ | n ≥ 0 } не е КСЕ

**Доказателство** (от противоречие):

Допускаме, че L = { aⁿbⁿcⁿ | n ≥ 0 } е КСЕ → ∃ константа p.

Избираме **z = aᵖbᵖcᵖ** ∈ L, |z| = 3p ≥ p.

По лемата: z = uvwxy, |vwx| ≤ p, |vx| > 0, ∀i: uvⁱwxⁱy ∈ L.

**Анализ на vwx** (|vwx| ≤ p < 3p → не може да обхваща и трите блока):

| Случай | Съдържание на vx | При i=2 |
|--------|-----------------|---------|
| vwx ⊆ aᵖ | само a-та | #a се увеличи, #b=#c=p → не в L |
| vwx ⊆ bᵖ | само b-та | #b се увеличи, #a=#c=p → не в L |
| vwx ⊆ cᵖ | само c-та | #c се увеличи, #a=#b=p → не в L |
| vwx пресича a|b | само a и b | #c=p, #a или #b се увеличава → не в L |
| vwx пресича b|c | само b и c | #a=p, #b или #c се увеличава → не в L |

Във всеки случай uv²wx²y ∉ L — **противоречие**. Следователно L не е КСЕ. □

---

### 7. КСЕ не са затворени относно ∩

**Доказателство** (чрез контрапример):

Нека:
- L₁ = { aⁱbⁱcʲ | i, j ≥ 0 } — КСЕ (граматика: S → AB, A → aAb | ε, B → cB | ε)
- L₂ = { aⁱbʲcʲ | i, j ≥ 0 } — КСЕ (граматика: S → AB, A → aA | ε, B → bBc | ε)

$$L_1 \cap L_2 = \{a^n b^n c^n \mid n \geq 0\}$$

(думата е в L₁ → #a=#b; в L₂ → #b=#c; и двете → #a=#b=#c)

Но { aⁿbⁿcⁿ } не е КСЕ (доказано в т. 6) → **КСЕ не са затворени относно ∩**. □

---

### 8. КСЕ не са затворени относно ¬ (допълнение)

**Доказателство** (от противоречие + Де Морган):

Допускаме, че КСЕ са затворени относно ¬.

Знаем: КСЕ са затворени относно ∪.

За всеки два КСЕ A, B:
- Ā, B̄ са КСЕ (по допускане)
- Ā ∪ B̄ е КСЕ (затвореност относно ∪)
- $\overline{\bar{A} \cup \bar{B}}$ е КСЕ (по допускане)

Но по Де Морган: $\overline{\bar{A} \cup \bar{B}} = A \cap B$

Следователно A ∩ B е КСЕ → КСЕ са затворени относно ∩ — **противоречие** с т. 7. □

### Тип 1: Построяване на КСГ за даден КСЕ

*Изрично в конспекта: „По даден КСЕ да се построи КСГ с обосновка"*

**Стандартни шаблони:**

**Равен брой два символа** { aⁿbⁿ | n ≥ 1 }:
```
S → aSb | ab
```

**Балансирани скоби** { w | w е балансирана скобна редица }:
```
S → SS | (S) | ε
```

**Палиндроми** над {a,b}:
```
S → aSa | bSb | a | b | ε
```

**Два блока с равен брой** { aⁿbᵐ | n ≠ m }:
```
S → A | B
A → aAb | aA | a    (повече a-та)
B → aAb | Bb | b    (повече b-та)
```

**Обосновка = 2 части:**
1. **Коректност**: Всяка дума, изведима от G, е в L (по индукция по броя стъпки)
2. **Пълнота**: Всяка дума в L може да се изведе от G (по индукция по n или дължината)

---

### Тип 2: Доказване, че език НЕ е КСЕ (чрез Лемата за разрастването)

*Изрично в конспекта: „Да се определи дали даден език е КСЕ с обосновка"*

**Алгоритъм (proof by contradiction):**

1. Допускаме, че L е КСЕ → ∃ константа p.
2. Избираме конкретна дума **z ∈ L с |z| ≥ p** (обикновено с параметър p).
3. Разглеждаме **всички възможни** разбивания z = uvwxy с |vwx| ≤ p, |vx| > 0.
4. За всяко такова разбиване намираме i (обикновено i=0 или i=2), за което uvⁱwxⁱy ∉ L.
5. Противоречие → L не е КСЕ.

**Шаблон за обосновка:**

> „Допускаме, че L е КСЕ. Нека p е константата на разрастване. Избираме z = [конкретна дума с p] ∈ L. Всяко разбиване z = uvwxy с |vwx| ≤ p, |vx| > 0 трябва да е такова, че [анализ на случаите]. Във всеки случай при i = [0 или 2] получаваме uvⁱwxⁱy = [дума] ∉ L, защото [причина]. Противоречие — L не е КСЕ."

**Чести примерни езици и думи:**

| Език | Дума z | Защо uvⁱwxⁱy ∉ L |
|------|--------|-----------------|
| { aⁿbⁿcⁿ } | aᵖbᵖcᵖ | vwx не покрива и трите блока → едни от #a,#b,#c не се менят |
| { aⁿbⁿcⁿdⁿ } | aᵖbᵖcᵖdᵖ | аналогично |
| { ww \| w ∈ {a,b}\* } | aᵖbᵖaᵖbᵖ | разрастването разрушава структурата ww |
| { aⁿ² } | aᵖ² | разрастването дава аⁿ²+k, но (p+k)² ≠ p²+k за 1 ≤ k ≤ p |
| { aⁱbʲcᵏ \| i<j<k } | aᵖbᵖ⁺¹cᵖ⁺² | промяна на един блок нарушава i<j<k |

**Важно**: Ако vwx пресича граница между два блока, тогава v и x могат да съдържат само 2 вида символи → 3-тият блок не се мени → равенствата/неравенствата се нарушават.

---

### Тип 3: Доказване, че език е КСЕ

Ако езикът е от прост вид (вложена структура, равен брой), построи граматиката директно (Тип 1).

Ако е по-сложен — използвай затвореност: ∪, ·, \* запазват КСЕ.

**Пример**: L = { aⁿbᵐ | n ≠ m } = { aⁿbᵐ | n > m } ∪ { aⁿbᵐ | n < m } — и двата са КСЕ → L е КСЕ.
